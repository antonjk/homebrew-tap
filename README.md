# antonjk/homebrew-tap

A [Homebrew](https://brew.sh) tap for my projects.

## Usage

```bash
brew tap antonjk/tap
brew install janus
```

Or in one step:

```bash
brew install antonjk/tap/janus
```

## Formulae

- **janus** — run annotated shell scripts as concurrent, grouped,
  progress-tracked steps. <https://github.com/antonjk/janus>
